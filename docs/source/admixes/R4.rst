R4
===

.. _R4c-admix:

The `R4-admix repository <https://github.com/RCIC-UCI-Public/R4-admix/>`_ uses **YAML2RPM** to build 
multiple versions of R4 and Rstido. 

R4 is relatively complex build and requires local changes to its Makefile to
accomplish multiple builds.

.. warning:: 
  
  This process will install RPMs as it builds. You should do this on a
  'disposable' build system. It takes hours to compile multiple versions of R4.

Here is the full process for building R4 using the  `R4-admix repository <https://github.com/RCIC-UCI-Public/R4-admix/>`_

.. code-block:: bash

   git clone https://github.com/RCIC-UCI-Public/R4-admix.git
   cd R4-admix
   make download
   cd yamlspecs
   (make bootstrap &> /tmp/bootstrap-gcc.log; make &> /tmp/build-gcc.log) &
